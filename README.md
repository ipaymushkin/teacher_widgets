# Teacher Widgets

Сайт-инструменты для учителей (контрольные, генераторы талонов и т.д.).

Стек: React + TypeScript + Vite + [shadcn/ui](https://ui.shadcn.com/).

## Запуск

```bash
npm install
npm run dev
```

## Скрипты

- `npm run dev` — локальная разработка
- `npm run build` — production-сборка
- `npm run preview` — просмотр сборки
